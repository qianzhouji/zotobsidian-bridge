# C3-C4 Development and Acceptance Progress

Updated: 2026-11-06 22:59 Asia/Shanghai. Status: **C3/C4 implementation and isolated-host checks substantially passed; native Chinese IME composition acceptance remains open. Do not mark the C0-C4 series complete yet.**

## Implemented

### C3: Wiki-link completion

- Reader popup textarea and expanded CodeMirror editor use the shared completion/query logic.
- Supports note-name/path/alias candidates, `#` heading and `#^` block lookup, pagination, 120 ms debounce, stale-generation cancellation, loading/empty/offline states, keyboard selection, Escape, and closing delimiters.
- Replacement is limited to the current link token. CodeMirror uses the completion framework's replacement range and one isolated-history transaction; its candidate rows also handle pointer acceptance directly. Reader uses native `insertText` and fails closed if it cannot preserve the undo path.
- IME composition suppresses completion and insertion until composition ends. This is implemented but still requires a real macOS input-method acceptance run in both editors.

### C4: Read-only knowledge-note card

- A reusable read-only panel is wired into Reader and expanded editors; nested links open another read-only card surface. Multi-card groups and relationship connectors are C5, not part of this implementation.
- Displays a frontmatter `title`, otherwise the first H1, then the filename; shows the resolved path and read-only state.
- Renders the whole ordinary Markdown note, hides valid YAML frontmatter and recognized Bridge payloads only in the display layer, and preserves source offsets for anchors.
- Supports headings, lists, tables, disabled task checkboxes, code, math, internal/external links and bounded local PNG/JPEG/GIF/WebP resources. Remote images and unsupported embeds remain inert placeholders.
- Refresh preserves a visible-line/scroll anchor. Open-in-Obsidian revalidates the target first. Close, navigation, cancellation and permission-scope changes dispose rendered object URLs and clear stale content.
